# مانا | لندینگ چاپ UV DTF

نسخه ۱۴ پروژه مانا؛ یک وب‌سایت تک‌صفحه‌ای فارسی، راست‌چین و واکنش‌گرا با React و Vite.

## ساختار پروژه

```text
mana-landing-project-2026/
├── public/
│   ├── .htaccess              # تنظیمات کش و فشرده‌سازی برای Apache/cPanel
│   └── assets/                # تصاویر و لوگوی سایت
├── scripts/
│   └── build.mjs              # ساخت خروجی متناسب با مقصد انتشار
├── src/
│   ├── components/            # اجزای مستقل صفحه
│   ├── data/
│   │   └── siteContent.js     # متن‌ها، اطلاعات تماس و فهرست‌ها
│   ├── hooks/
│   │   └── useScrollReveal.js # انیمیشن ورود بخش‌ها هنگام اسکرول
│   ├── styles/
│   │   └── site.css           # استایل و طراحی تأییدشده مانا
│   ├── App.jsx                # ترتیب و ترکیب بخش‌های صفحه
│   └── main.jsx               # نقطه ورود React
├── index.html
├── package.json
└── vite.config.js
```

## پیش‌نیاز

- Node.js نسخه ۲۰ یا جدیدتر
- npm

## اجرا در ویندوز و VS Code

ترمینال را در پوشه اصلی پروژه باز کنید:

```powershell
npm.cmd install
npm.cmd run dev
```

آدرس محلی که Vite نمایش می‌دهد را در مرورگر باز کنید.

## ساخت خروجی برای هاست لینوکس cPanel

```powershell
npm.cmd run build:host
```

خروجی آماده انتشار در پوشه `dist` ساخته می‌شود. در cPanel وارد **File Manager** شوید و تمام محتویات پوشه `dist` را داخل `public_html` آپلود کنید. فایل مخفی `.htaccess` را نیز آپلود کنید. نیازی به نصب Node.js روی هاست نیست.

## ساخت خروجی GitHub Pages (در صورت نیاز)

در PowerShell نام ریپازیتوری را در مسیر زیر قرار دهید:

```powershell
$env:GITHUB_PAGES_BASE="/نام-ریپازیتوری/"
npm.cmd run build:github
```

خروجی GitHub Pages هم در پوشه `dist` ساخته می‌شود. قبل از ساخت خروجی مقصد بعدی، محتوای قبلی `dist` به‌صورت خودکار پاک می‌شود.

## محل ویرایش محتوا

متن‌ها، شماره تماس، آدرس، ایمیل، لینک اینستاگرام، خدمات، کاربردها و مشخصات نمونه‌کارها در فایل زیر متمرکز شده‌اند:

`src/data/siteContent.js`

متن‌های بخش‌های اصلی صفحه در کامپوننت‌های پوشه `src/components/` قرار دارند. ترتیب بخش‌ها در `src/App.jsx` مشخص شده است.

## تصاویر و سرعت بارگذاری

- تصویر دستگاه هیرو با اولویت بالا و بدون Lazy Loading بارگذاری می‌شود.
- تصاویر نمونه‌کارها Lazy Loading دارند.
- چهار تصویر اصلی با فرمت WebP در `public/assets/` قرار دارند.
- ابعاد تصویرها در HTML مشخص شده تا پرش چیدمان هنگام بارگذاری کمتر شود.
- تنظیمات کش مرورگر و فشرده‌سازی در `.htaccess` برای هاست Apache قرار گرفته است.

## نکته انتشار

برای cPanel از خروجی `build:host` استفاده کنید. مسیرها به‌صورت نسبی ساخته می‌شوند تا سایت در ریشه دامنه یا یک زیرپوشه قابل اجرا باشد.
